# Static Site Generator Project
I built a static site generator that creates HTML pages from content files. 

Please note: "static site" means that the final site is files (i.e., HTML, CSS, images, and perhaps JS). There is no backend server generating pages on request. 

## Project Overview
This generator
- reads Markdown files from content/
- converts Markdown into HTML
- wraps that HTML in template.html
- copies static assets like CSS/images
- outputs a finished website into docs/ or public/

## TL;DR
You can use this generator to replace the Tolkien Markdown with any content (e.g., blog posts, documentation, a company homepage, portfolio pages, etc.) to produce a different static website. You can also change the template, styles, and images.
